# Emretuna Tap

## How do I install these formulae?

`brew install emretuna/tap/<formula>`

Or `brew tap emretuna/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "emretuna/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
